# Pet Care Product CRUD Application

## Introduction

An application build using Laravel + React with functionality to do CRUD on pet care products. Mainly built based on ["PHP Laravel Project Example for Beginners"](https://phppot.com/php/php-laravel-project-example/) by PHPPot, but with modification to use newer version of Laravel and React.
